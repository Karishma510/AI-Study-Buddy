# AI-Study-Buddy

An AI-powered study assistant that helps students understand topics in simple language, summarize notes, and generate quizzes instantly.

Built with Python, Streamlit, and Google Gemini API to support efficient self-learning.

## Features
- Topic explanation in simple language
- AI-generated quizzes
- Smart note summarization
- Fast and lightweight UI

## Tech Stack
- Python
- Streamlit
- Gemini API
